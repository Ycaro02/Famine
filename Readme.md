# famine

## Description

Famine is a binary that modifies one or multiple binaries by applying a
signature, without modifying the original behavior of the targeted
binary(ies).

The signature is represented by a line containing your specific logins.

Since this program is meant to behave like a virus, no output will be
produced.

## Setup

The program requires sudo privileges.

### Base program

``` bash
make && sudo ./Famine
```

### Bonus program

To run the full bonuses, you need the following environment variables:

FAMINE_WOODY_ENABLE: if defined, starts woody_woodpacker in bonus mode.\
FAMINE_ROOT_PATH: redefines the root path, defaults to '/'.

``` bash
export FAMINE_WOODY_ENABLE=true
export FAMINE_ROOT_PATH='/home'
```

``` bash
make bonus && sudo ./Famine
```

## Bonus Flags (Woody Control Only)

-   {"verbose", 'v'}: controls log verbosity (debug only, not useful
    during correction)
-   {"help", 'h'}: displays help (debug only, not useful during
    correction)
-   {"key", 'k'}: encryption key for infected binaries (randomly
    generated by default)
-   {"size", 's'}: encryption key size (16 by default, 256 maximum)
-   {"command", 'c'}: shell command injected into infected binaries
    (empty by default)
-   {"argument", 'a'}: injected command type
    -   1: executes the argument provided with `-c`\
    -   2: only displays the argument

## Examples

``` bash
./famine -c /bin/ls -a 1
```

Executes the `ls` command inside the infected binary.

``` bash
./famine -c koala -a 2
```

Executes an `echo koala` inside the infected binary.
